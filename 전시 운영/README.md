# 전시 운영

## 다른 컴퓨터에서 사용

`전시 운영.zip`을 Windows 컴퓨터에 복사해 압축을 **모두 해제**하세요. 압축 해제한 폴더 안의 **전시 시작.exe**를 더블클릭하면 로컬 전시 서버와 Chrome 전시 창이 열립니다. Chrome이 없으면 Microsoft Edge 창이 열립니다. 끝날 때 **전시 종료.exe**를 더블클릭하면 해당 전시 창과 서버만 종료합니다. 일반 브라우저 창은 닫지 않습니다.

Windows 10/11, .NET Framework 4.x, Chrome 또는 Edge, 카메라와 소리 출력 장치가 필요합니다. Node.js와 인터넷 연결은 필요하지 않습니다. 첫 실행 때 카메라 권한을 허용하고 화면의 **운영 설정 → 카메라·소리 연결**을 누르세요. 전시 주소는 `http://127.0.0.1:8026/`이며 기본 화면은 2번 버전입니다. 운영 설정에서 5번 버전으로 이동할 수 있습니다.

8026 포트를 다른 프로그램이 사용 중이면 시작 EXE에 오류가 표시됩니다. 이 EXE는 코드 서명이 없어 다른 컴퓨터에서 Windows 보안 경고가 나올 수 있으므로 전시 전에 한 번 실행해 확인하세요.

**R 키**는 현재 버전의 참여 기록과 인원 수를 모두 지워 0명으로 초기화합니다. 되돌릴 수 없습니다. 2번과 5번의 기록은 서로 분리됩니다.

참여 기록과 카메라 권한은 해당 컴퓨터의 `%LOCALAPPDATA%\HZ_Portal_Exhibition\ChromeProfile` 또는 `EdgeProfile`에 보관됩니다. 전시 폴더나 ZIP을 다른 컴퓨터로 복사해도 참여 기록은 옮겨지지 않습니다.

## 웹 최종본으로 다시 만들기

프로젝트 컴퓨터에서 `Project/web`을 수정한 뒤 `전시 운영/build.ps1`을 PowerShell로 실행하세요. 이 스크립트는 `web` 복사본, 두 EXE, `전시 운영.zip`을 다시 만듭니다. 전시장 컴퓨터에서는 빌드가 필요하지 않습니다.
