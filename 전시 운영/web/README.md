# WHAT REMAINS — 민트 무빙 포스터

## 실행

`Start.cmd`를 실행하고 Chrome에서 http://127.0.0.1:8026/version-2.html 을 엽니다.
운영 설정 → 카메라·소리 연결을 누릅니다. 관객은 한 손을 머리 위로 약 1.1초 유지한 다음 10초 동안 움직입니다.
O 설정, Enter 연결, Esc 닫기, F11 전체 화면. R은 현재 버전의 모든 기록과 참여 인원을 지웁니다.

## 확정한 표현

- 최신 첨부 순서의 3번 원본 `exec-9c30ef7e…`를 사용합니다. 프로젝트 자산은 `assets/approved-afterimages/05.png`입니다.
- 실제 참여자의 전경 마스크가 자세·신체 비율·팔 외곽을 결정합니다. 원본 인물 그림을 이동하거나 휘는 방식은 사용하지 않습니다.
- 승인 이미지에서는 컬러 조합·그라데이션·투명한 중심부·부드러운 광학 번짐만 가져옵니다. 사람별 원본 윤곽은 그대로 유지하고 외곽에 색 번짐을 합성합니다.
- 10초 동안 실제로 기록한 자세가 계속 재생됩니다. 색상 5종, 크기 30~90%, 불투명도 70~100%, 0.65배속, 음악·안내·타이틀 설정은 유지합니다.
- 녹화는 10초 그대로, 재생은 0.65배속입니다. 전체 동작 한 바퀴는 약 15.38초입니다. 연결 부분만 짧게 페이드합니다.
- 원본 웹캠 영상·음성 대신 좌표·전경 외곽·타임스탬프를 로컬 IndexedDB에 저장합니다. 영상 파일 내보내기는 없습니다.
- 대기 안내는 손 들기 / 10초 움직임 두 줄을 강조합니다. 관객에게 불필요한 연결 상태는 숨기고 운영 설정에서 확인합니다.
- 포스터의 큰 글자는 유지하고, X 표시한 작은 양쪽 문구를 제거한 `assets/mint-title-plate-clean.png`를 사용합니다.
- 참여 전에는 잔상이 없고 실제 참여에 따라 누적됩니다. 기존 전시 기록은 자동 삭제하지 않습니다. 결과는 22초 표시한 뒤 대기로 돌아갑니다.

## 저장과 검증

2번/5번 저장소는 분리되어 있습니다. 같은 Chrome 프로필·주소에서 새로고침하면 기록을 복원합니다. 브라우저 데이터 삭제는 기록을 삭제합니다. 카메라/저장 실패는 운영자 안내를 표시하며, 실패한 참여는 인원에 더하지 않습니다.

`node --test art.test.mjs imprint.test.mjs interaction.test.mjs motion.test.mjs reliability.test.mjs silhouette.test.mjs`

`motion.browser-check.html`은 전시 저장소와 분리된 QA 저장소에서 가상 손짓, 10초 기록, 재생, 복원, R 초기화, 오류 복구를 검사합니다. `?preview=6`은 저장되지 않는 6명 예시입니다. 현장의 실제 사람 인식과 스피커 청취는 운영 장비에서 확인해야 합니다.

60개 합성 위상을 미리 만들어 재생합니다. 많은 인원의 기록 복원에는 시간이 늘어납니다. 1.6만 명 장기 운영·자동 백업은 아직 검증/구현되지 않았습니다. OS 동작 줄이기 설정에서는 정지 프레임으로 표시합니다.

수정 전 주요 코드: `../backups/before-source-trace-20261113/`.

자세 연동 수정 검증: Node 관련 검사 10개, Chrome 가상 체험 흐름 25개, 공개 사진 기반 실제 MediaPipe 외곽 검사 5개 통과. 고정 위치·동일 색상에서도 서로 다른 팔 외곽이 다른 픽셀로 렌더링되는 회귀 검사를 포함합니다. 현장 사람의 실제 10초 체험 검사는 별도입니다.
