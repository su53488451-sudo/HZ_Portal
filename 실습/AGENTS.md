# 프로젝트 목표

- 크롬에서 실행하는 웹캠 기반 포털 인터랙션을 만든다.
- 콘셉트는 **숲 속의 나**다. 숲 배경에서 박수를 치거나 마우스를 드래그하면 백합이 피어나고, 꽃 안에 웹캠 속 내 얼굴이 나타난다.
- 손짓 입력은 웹캠을 활용한다. 박수 판별 방식 등 구현 세부 사항이 불분명하면 해당 단계에서 가정을 밝히고 확인한다.
- 로컬 실행과 확인에는 크롬과 파이썬 서버를 사용한다.

# 함께 작업하는 방식

- 웹개발자로서 한국어로 쉽고 짧게 설명한다. 전문 용어가 필요하면 바로 뜻을 풀어 쓴다.
- 한 단계씩 진행한다. **현재 요청한 단계만 진행하고 결과를 확인한다.** 다음 단계의 화면이나 기능을 미리 만들지 않는다.
- 각 단계 전에 할 일과 확인 방법을 간단히 말하고, 끝나면 실제 확인 결과와 사용자가 할 일을 짧게 전한다.
- 사용자 요구가 여러 뜻으로 해석되면 가정을 드러낸다. 중요한 선택은 해당 단계에서 확인한다.
- 추가 스킬은 실제로 필요할 때만 추천한다.

# 코딩 기준

- [karpathy-guidelines](https://github.com/multica-ai/andrej-karpathy-skills/blob/2c606141936f1eeef17fa3043a72095b4765b9c2/skills/karpathy-guidelines/SKILL.md)를 적용한다: 구현 전에 가정과 확인 기준을 밝히고, 요청을 해결하는 가장 단순한 방법을 택한다.
- 요청과 직접 관련된 파일과 코드만 수정한다. 기존 파일을 바꿀 때는 현재 스타일을 존중하고 불필요한 정리나 기능 추가를 하지 않는다.
- 작동 여부를 실제로 확인하고, 확인하지 못한 부분은 확인했다고 말하지 않는다.

# 현재 단계

- 계획, 기존 파일 및 실행 환경 확인, 이 작업 규칙 작성까지만 한다.
- 화면 제작과 인터랙션 구현은 다음 요청부터 시작한다.
