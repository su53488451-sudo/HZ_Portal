# 움직임의 잔상 — 다크 전시 버전

확정한 다크 시안의 컬러·빛 번짐을 적용한 로컬 웹입니다. 글자는 실제 HTML과 로컬 Pretendard 폰트로 표시하며, 하단에는 `손을 들어 시작 → 10초의 움직임 → 하나의 풍경`을 안내합니다.

## 실행

1. `Start.cmd`를 실행합니다. Node.js가 없으면 설치된 Python 런처를 사용합니다.
2. Chrome에서 http://127.0.0.1:8026/ 을 엽니다. 실행 창은 열어 둡니다.
3. 처음 나타나는 운영 창의 **카메라·소리 연결**을 누르고 카메라 권한을 허용합니다. 연결되면 운영 창이 닫힙니다.
4. F11로 전체 화면을 켭니다. 관객은 한 손을 머리 위로 약 1.1초 유지해 시작합니다.

운영자의 마우스는 정상 작동합니다. 오른쪽 위 **운영 설정**으로 운영 창을 다시 열 수 있습니다. 단축키는 Enter 연결, O 운영 창, Esc 닫기입니다. 관객용 클릭·터치 버튼은 없습니다.

새로고침하면 브라우저의 소리 자동 재생 제한 때문에 운영자가 연결 버튼을 한 번 눌러야 합니다.

## 대기 포스터와 모션

- 확정 시안에서 글자와 UI를 제거해 만든 `assets/afterimage-poster-v1.png`를 기본 작품으로 사용합니다. 실시간 화면 전체를 이미지로 붙여 놓은 방식이 아닙니다.
- 잔상의 색이 있는 부분만 골라 약 52초 주기의 넓은 빛이 천천히 지나갑니다. 글자·배경 전체는 깜박이지 않습니다. 약 31초 주기의 작은 밝기 변화도 함께 적용합니다.
- 미세한 노이즈는 고정되어 있어 프레임마다 지글거리지 않습니다.
- 참여자가 생기면 기본 작품을 은은하게 낮추고, 실제 좌표로 생성한 잔상을 계속 겹칩니다. 누적된 잔상에도 같은 빛 모션이 적용됩니다.
- 운영체제의 동작 줄이기 설정에서는 대기 모션을 멈춥니다. 비활성 탭에서는 렌더링을 멈춥니다.
- 기본 작품의 잔상은 장식이며 **참여 인원에 포함되지 않습니다.**

## 참여 인원: 0명부터

새 전시 저장소 `forms-of-presence-dark-20261112`에서 **0000**으로 시작합니다. 실제 참여가 저장되면 0001, 0002처럼 증가합니다. 새로고침해도 이후 기록과 참여 수는 유지됩니다.

이전 `forms-of-presence-v1` 저장소의 기록은 삭제하지 않았습니다. 이번 전시에 자동 합치지 않습니다. 이전 코드 백업은 프로젝트의 `backups/before-dark-20261112`에 있습니다.

사진이나 웹캠 영상은 저장하지 않습니다. 이동 좌표·마지막 팔 자세·팔레트·시각만 Chrome의 IndexedDB에 저장합니다. 같은 컴퓨터라도 접속 주소나 브라우저 프로필이 다르면 기록이 별도로 보관됩니다. 운영 중에는 동일한 주소와 프로필을 사용합니다.

## 참여 흐름

1. 상체와 두 손을 카메라에 보여 줍니다.
2. 한 손을 머리 위로 잠시 유지합니다.
3. 10초 카운트와 소리가 나오고 양 손목의 움직임을 읽습니다.
4. 이동 궤적과 마지막으로 인식한 팔 자세가 색이 번지는 추상 잔상으로 추가됩니다. 기성 도형을 고르는 방식이 아닙니다.
5. 결과를 10초 보여 준 뒤 다시 대기 포스터로 돌아옵니다. 다시 시작하려면 손을 한 번 내렸다가 들어야 합니다.

블루+핑크/레드, 레드+그린, 블루+옐로, 그린+옐로, 코랄+바이올렛, 시안+핑크 팔레트를 순환합니다. 컬러가 모든 사람에게 영구적으로 고유한 것은 아닙니다.

## 확인한 사항

- `node --test art.test.mjs interaction.test.mjs`: 11개 통과.
- `/art.browser-check.html`: 4개 통과. 기본 포스터의 빛 변화, 동작 줄이기의 정지 프레임, 참여 잔상의 빛 변화, 좌표 불변을 실제 Canvas 픽셀로 검사합니다.
- Chrome 가로형 1440×810에서 배치·하단 안내·0000 표시 확인. 새로고침 후에도 0000 유지 확인.
- 별도 검사 화면에서 마우스로 카메라·오디오 연결 및 운영 창 자동 닫힘/다시 열기 확인. 브라우저 오류 없음.
- 실제 관객의 손들기부터 10초 체험·저장까지의 전체 흐름과 스피커 출력은 현장에서 최종 확인해야 합니다.

`?test=1`은 별도 검사 저장소, `?preview=1`은 저장되지 않는 예시 궤적 미리보기입니다. 실전 주소는 매개변수 없는 `/`입니다.

현재 화면 캡처: `dark-preview.jpg`. 모델과 폰트, 배경은 모두 로컬 파일입니다. 장기 무인 운영 16,000명에 대한 부하 검사와 외부 백업은 아직 구축하지 않았습니다.
