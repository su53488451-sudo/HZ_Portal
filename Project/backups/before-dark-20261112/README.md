# 움직임의 잔상 — 빛 번짐 버전

참고 이미지의 어두운 중심, 빛이 번지는 가장자리, 겹치는 색을 Canvas로 표현합니다. 이미지 자체를 배경으로 쓰지 않습니다. 반복되는 결·등고선·종이 질감을 없앴으며, Pretendard와 기존 중앙 안내 배치는 유지합니다.

## 실행과 운영 준비

`Start.cmd`를 실행하고 Chrome에서 http://127.0.0.1:8026 을 엽니다. 실행 창은 열어 둡니다. Node.js가 없으면 Python 런처를 사용합니다.

- 처음 열리는 운영 창에서 **카메라·소리 연결** 버튼을 마우스로 누릅니다. 최초 접속 때 크롬 카메라 권한을 허용합니다. Enter 단축키도 사용할 수 있습니다.
- 연결이 완료되면 운영 창이 자동으로 닫히고 손짓 체험을 받을 수 있습니다.
- 왼쪽 아래 **운영 설정**을 마우스로 눌러 운영 창을 다시 엽니다. 닫기 버튼도 마우스로 작동합니다. O / Esc 단축키도 유지합니다. 카메라 확인 화면은 운영 창 안에만 있습니다.
- 전체 화면은 크롬의 **F11**을 사용합니다.
- 브라우저의 소리 자동 재생 제한 때문에 새로고침하거나 다시 열 때 운영자가 연결 버튼을 한 번 눌러야 합니다. 관객은 마우스나 터치를 사용하지 않습니다.

## 참여 흐름 — 마우스·터치 불필요

1. 참여자가 상체와 두 손을 화면 안에 보여 줍니다.
2. 한 손을 머리 위로 약 1.1초 유지하면 자동으로 시작합니다.
3. 10초 카운트와 소리가 나오고 양 손목의 움직임을 기록합니다.
4. 이동 궤적과 마지막 팔 자세가 색이 번지는 잔상으로 나타나 기존 포스터 위에 겹쳐집니다.
5. 결과를 10초 보여 준 뒤 다음 참여 안내로 자동 복귀합니다. 다음 체험은 손을 한 번 내린 뒤 시작합니다.

관객용 시작·마우스 체험·포스터 보기·이미지 저장·다음 참여 버튼은 제거했습니다. 운영자용 마우스 커서와 운영 설정·연결·닫기 버튼은 사용할 수 있습니다. 손을 계속 들고 있거나 추적이 잠시 끊기는 것만으로 다음 체험이 반복 시작되지 않습니다.

## 표현과 저장

- 밝고 차가운 블루그레이 바탕. 코발트·라일락·핑크·코랄·민트의 채도를 높이고 번짐 폭을 줄여 형태를 선명하게 보여 줍니다.
- 궤적의 꺾임·길이·닫힘 여부와 마지막 팔 자세로 형태를 만듭니다. 곧게 뻗는 움직임은 길고 얇게, 크게 닫힌 움직임은 고리로, 팔 자세는 넓거나 접힌 면으로 표현합니다. 정해진 기호를 선택하지 않습니다.
- 선이나 기성 기호를 고르는 방식이 아닙니다. 팔레트는 순환하므로 컬러의 완전한 고유성은 보장하지 않습니다.
- 첫 화면의 장식은 참여 기록에 포함하지 않습니다. 기록이 생기면 그 기록이 첫 화면 배경이 됩니다.
- 기존 `forms-of-presence-v1` 기록은 그대로 두고 새 표현 방식으로 다시 그립니다.
- 영상·사진은 저장하지 않으며, 좌표·팔레트·생성 시각만 브라우저 IndexedDB에 저장합니다. 모델과 글꼴도 로컬 파일을 사용합니다.
- 브라우저 사이트 데이터를 삭제하면 기록도 삭제됩니다. 16,000명 규모의 장기 운영을 위한 백업 및 부하 검증은 아직 수행하지 않았습니다.

## 검증과 미리보기

`node --test art.test.mjs interaction.test.mjs`로 좌표 기반 형태와 손들기 유지 시간, 재시작 방지, 추적 손실 처리를 검사합니다.

- `?preview=1`: 여섯 개의 예시 궤적으로 번짐 표현만 확인합니다. 카메라를 켜거나 기록을 저장하지 않습니다.
- `?test=1`: 전시 기록과 분리된 검증용 저장소입니다.
- `?setup=1`: 운영자 준비 화면을 열어 시작합니다.

실제 관람객의 손들기부터 카운트·저장까지의 전체 흐름과 스피커 출력은 설치 장소에서 최종 확인해야 합니다.

이번 수정 검증: 검사 11개 통과. Chrome에서 마우스 클릭으로 카메라·오디오 활성화, 운영 창 자동 닫힘, 설정 다시 열기와 닫기 확인. 기존 참여 기록 3개 유지 확인. 상단은 참여형 미디어 아트만, 하단은 운영 설정과 누적 수만 표시합니다. 손들기 안내를 확대하고 아이콘과 중복 설명을 제거했습니다. `preview.jpg`는 실제 대기 화면이며 `diffusion-preview.jpg`는 예시 궤적 6개의 표현 미리보기입니다.
