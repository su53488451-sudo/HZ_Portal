# WHAT REMAINS — 민트 무빙 포스터

## 실행

Start.cmd를 실행한 뒤 크롬에서 아래 주소를 엽니다. 이 PC에서는 Node.js를 사용합니다.
- 2번 민트 타이포: http://127.0.0.1:8026/version-2.html
- 5번 컬러 오버프린트: http://127.0.0.1:8026/version-5.html
- 가로형 디자인 비교: http://127.0.0.1:8026/design-review.html (6명 가상 예시, 실제 저장 없음)

운영자가 카메라·소리 연결을 한 번 클릭합니다. 카메라 권한을 허용하고 F11로 전체 화면을 사용합니다. 운영 설정은 O, 연결은 Enter, 닫기는 Esc입니다. 관객은 마우스나 터치 없이 한 손을 머리 위로 1.1초 유지해 시작합니다.

## 체험과 누적

1. 각 버전 최초 실행은 0000명, 잔상 없는 밝은 바탕으로 시작합니다.
2. 손을 들면 10초 카운트와 비프음이 진행됩니다. 어깨·팔꿈치·손목·머리·골반 위치를 시간과 함께 기록합니다. 골반이 화면 밖이면 상체 기반 보조 윤곽으로 표현합니다.
3. 10초 전체 동작이 작은 인체 잔상으로 반복됩니다. 머리·목·몸통과 어깨→팔꿈치→손목의 실제 위치를 따라 형태를 그려, 팔의 방향과 자세 변화가 읽히게 합니다. 가장자리는 그라데이션·번짐과 240ms 전 자세의 잔광으로 표현합니다. 마지막 자세 한 장을 저장하는 방식이 아닙니다.
4. 참여할 때마다 새로운 색과 위치의 잔상이 기존 잔상 위에 겹칩니다. 칸이나 카드에 배치하지 않습니다. 오래된 기록도 함께 움직입니다.
5. 결과 포스터를 22초 보여 준 뒤 참여 안내로 돌아갑니다. 대기 중에도 누적된 잔상은 움직입니다. 다음 참여 전에는 손을 한 번 내려야 합니다.

기록은 웹캠 원본 영상이나 음성이 아니라, **10초 동안 인식한 자세 좌표와 타임스탬프**입니다. MP4/WebM 내보내기는 없습니다. 350ms 넘게 놓친 구간은 임의로 연결하지 않습니다. 유효 인식이 총 6.5초 미만이거나 시작·끝 구간이 빠지면 저장하지 않고 재시도를 안내합니다. 인식이 끊기면 먼저 자세 안내를 표시하고, 약 3.6초 이상 회복되지 않으면 체험을 취소합니다. 창 숨김/운영 패널 열기도 진행 중 체험을 취소합니다.

손 들기 진행 표시 → 10초 카운트 → 포스터를 만드는 중 → 내 잔상 안내 순서로 진행됩니다. 처음 8초 동안 새 잔상의 위치를 표시합니다. 카메라 권한 거부·연결 지연·인식 중단·저장 실패에는 복구 방법이 나옵니다. 저장 실패는 참여 인원을 늘리지 않습니다.

민트 포스터는 승인한 exec-e926ae7d 이미지의 개별 글자 위치·크기를 기준으로 SVG 타이틀을 고정 배치합니다. 타이틀 글로우·번짐, 반투명 가로 면, 미세한 노이즈를 사용합니다. 처음에는 잔상이 없으며, 관객이 참여할 때마다 새 잔상이 더해집니다. 5번 버전도 별도 주소와 저장소로 남겨 두었습니다.

## R 초기화

R 키 또는 운영 설정의 초기화 버튼은 **현재 버전의 모든 참여 기록과 인원을 삭제하고 0명으로 돌립니다.** 진행 중 기록과 결과 재생도 취소합니다. 다른 버전과 이전 에디션 저장소에는 영향을 주지 않습니다. 초기화는 되돌리기 기능이 없으므로 운영자가 사용합니다.

2/5번은 각자 별도의 로컬 IndexedDB에 저장됩니다: what-remains-edition-2-live-v2 / what-remains-edition-5-live-v2. 새로고침은 기록을 유지합니다. 동일한 Chrome 프로필과 주소를 사용해야 합니다. 브라우저 데이터 삭제는 기록을 삭제합니다.

## 렌더링과 운영 범위

10초 동작을 약 80~140ms 간격으로 저장하고, 60개 합성 위상과 사이 프레임 혼합으로 재생합니다. 새 참여자는 기존 캐시에 추가되므로 매 화면마다 전체 인원을 다시 계산하지 않습니다. 캐시 폭은 최대 720px로 제한하고, 글자는 화면 해상도로 표시합니다. 부드러운 광학 번짐을 위한 선택입니다.

새로고침/화면 크기 변경 시 전체 동작으로 캐시를 다시 구성합니다. 대규모 누적 시 이 준비 시간과 저장 공간이 늘어나며, 겹침도 조밀해집니다. 1.6만 명 장기 운영, 브라우저 용량 한계, 자동 백업은 아직 검증/구현되지 않았습니다. OS의 동작 줄이기 설정이 켜져 있으면 접근성을 위해 정지 프레임으로 표시합니다.

## 검증

2026-11-13 확인: Node 검사 20개와 Chrome 브라우저 검사 23개 통과. 실제 웹캠 연결·MediaPipe 로딩·오디오 활성화 상태 확인. 브라우저 검사의 손짓과 기록 입력은 가상 좌표이며, 사람의 실제 체험과 스피커 청취를 대신하지 않습니다.

node --test art.test.mjs interaction.test.mjs motion.test.mjs reliability.test.mjs

motion.browser-check.html은 QA 전용 저장소에서 가상 동작으로 손 들기 시작, 10초 기록, 저장, 재생 픽셀 변화, 누적 캐시, 새로고침, R 초기화, 버전 분리, 저장 실패, 추적 중단, 카메라 오류, 미리보기 크기 변경을 검사합니다. 운영 설정의 10초 리허설도 실제 관객 수에 포함되지 않습니다. 실제 사람의 손짓 인식과 현장 스피커 소리는 전시 장비에서 최종 확인해야 합니다.
