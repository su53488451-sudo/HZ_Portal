# WHAT REMAINS — 움직임의 잔상 / 무빙 포스터

## 실행

`Start.cmd`를 실행하고 Chrome에서 http://127.0.0.1:8026/ 을 엽니다. 현재 PC는 Node.js를 사용합니다.
운영자가 **카메라·소리 연결**을 한 번 클릭하고 카메라 권한을 허용합니다. 연결 후 F11 전체 화면을 사용합니다.
관객은 마우스나 터치 없이 한 손을 머리 위로 약 1.1초 유지해 시작합니다. 운영 설정은 마우스 또는 O, 연결은 Enter, 닫기는 Esc입니다.

## 체험

1. 다크 안내 화면: WHAT REMAINS / 작은 한글 전시명, 상단 3단계, 중앙 손들기 안내, 하단 문구와 누적 인원.
2. 10초 동안 카운트와 비프음. 양 손목·팔꿈치·어깨 좌표를 시간과 함께 약 80~140ms 간격으로 기록합니다. 실제 처리 속도에 따라 달라집니다.
3. 같은 배경의 다크 컬러가 밝은 아이스 블루로 전환되고, 큰 영문 포스터 타이포그래피가 등장합니다.
4. 기록한 전체 동작을 원래 시간 순서와 속도로 10초 루프 재생합니다. 마지막 자세 한 장을 재생하는 방식이 아닙니다. 반복 경계는 짧게 페이드합니다.
5. 결과를 22초 보여 준 뒤 다크 안내로 돌아갑니다. 한 번 손을 내린 뒤 다시 올리면 새 체험이 시작됩니다.

## 실제로 기록하는 것

웹캠 원본 영상·음성은 저장하지 않습니다. 10초의 자세 좌표, 타임스탬프, 궤적, 팔레트만 로컬 IndexedDB에 저장하고 Canvas로 무빙 포스터를 재구성합니다. MP4/WebM 파일 내보내기는 이번 버전에 포함하지 않습니다.
350ms보다 긴 인식 누락 구간은 임의 보간하지 않습니다. 유효 인식이 총 2.5초 미만이면 저장하지 않고 재시도를 안내합니다. 창이 숨겨지거나 운영 패널을 열면 진행 중 기록을 취소합니다.

새 에디션 저장소는 `what-remains-motion-v1`입니다. 처음 0000에서 시작하며 새로고침하면 저장된 인원과 움직임을 복원합니다. 이전 에디션 기록은 삭제하지 않았습니다. 같은 Chrome 프로필과 주소를 유지해야 합니다.

## 누적과 성능 범위

모든 완료된 참여의 동작 데이터를 보관합니다. 화면에서는 최근 6명의 실제 동작을 동시에 재생하고, 더 이전 참여의 전체 궤적은 누적 배경에 남깁니다. 모든 과거 참여를 동시에 움직이게 만드는 방식은 아닙니다.
새로고침 때 전체 기록을 읽고 이전 궤적 배경을 재구성합니다. 16,000명 장기 운영의 메모리·저장 용량·재시작 시간·카메라 복구는 아직 실기기 부하 검증 전입니다. 외부 백업/포스터 영상 다운로드는 미구현입니다.

## 리허설 및 검사

운영 패널의 **움직임 예시로 10초 리허설**은 카메라 없이 합성 동작으로 진행합니다. 화면에 리허설 표시가 나오며 인원과 참여 기록은 증가하지 않습니다. 소리는 운영자 클릭으로 활성화됩니다.
`?preview=1`은 저장하지 않는 결과 포스터 예시입니다. 실제 전시 주소에는 쿼리를 붙이지 않습니다.

- `node --test art.test.mjs interaction.test.mjs motion.test.mjs`
- `/motion.browser-check.html`: 합성 동작으로 10초 기록, 픽셀 변화, IndexedDB 저장 및 새로고침 복원, 리허설 미저장 검사. `what-remains-motion-qa`만 사용합니다.
- 실제 사람의 손들기, 카메라 시야, 스피커 음량, 장시간 안정성은 현장에서 확인해야 합니다.
